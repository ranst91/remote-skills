Remote Skills is an open-source toolkit for publishing and consuming [Agent Skills](https://agentskills.io/) directly from remote origins.

Publish a skill once, then let your agents load it when they need it. Update your skills independently of the applications that use them.

## Built on open formats

[Agent Skills](https://agentskills.io/specification) defines the skill folder. [Agent Skills Discovery v0.2.0](https://github.com/cloudflare/agent-skills-discovery-rfc) defines how to find and download skills over HTTP. Remote Skills supplies the publishing tools and clients that bring them together.

You host the files and choose which publishers your agents trust. There is no marketplace or central service to join.

The [Quickstart](/docs/quickstart) brings both sides together with one small greeting skill.
