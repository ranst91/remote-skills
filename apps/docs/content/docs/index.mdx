Remote Skills joins two open formats: [Agent Skills](https://agentskills.io/specification) for a skill directory and Cloudflare Agent Skills Discovery **v0.2.0** for remote discovery. It adds a publisher CLI and server-runtime TypeScript and Python clients; it does not add a marketplace or central service.

```text
Discover metadata → activate by name → verify digest → pin for the session → read resources as needed
```

## Choose a path

- **Publish:** validate ordinary `skills/<name>/SKILL.md` directories, build `dist/`, then follow [archive to origin](/docs/hosting/archive-to-origin).
- **Host from Git:** let CI build from repository source, then follow [Git and Pages hosting](/docs/hosting/git-pages).
- **Consume:** open an origin-bound session from [TypeScript](/docs/typescript) or [Python](/docs/python).
- **Keep it local:** if skills belong to one application release, use the [local-or-remote decision guide](/docs/hosting/local-or-remote).

## The important boundary

Activation downloads the **complete artifact**, verifies its SHA-256 digest, and extracts archives into a local cache. Progressive disclosure is **context-lazy**, not network-lazy: `SKILL.md` enters context first and a later resource read uses local verified bytes without another network request.

The digest establishes byte integrity against the publisher catalog. It does not prove the instructions, scripts, or assets are safe. Remote Skills never executes them and never treats `allowed-tools` as permission.

## Requirements

- Node.js 24 or newer for the CLI, TypeScript client, and docs.
- Python 3.11 or newer for the async Python client.
- HTTPS origins in production. Explicit loopback development may use HTTP.

Continue with the [publisher guide](/docs/publisher), then verify the deployed origin before configuring consumers.
