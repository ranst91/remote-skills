title: Python client
description: Use the async remote_skills package with the same wire and cache semantics as TypeScript.

The distribution is named `remote-skills` and imports as `remote_skills`. It requires Python 3.11 or newer and is async-only.

Install the locally built and approved wheel; v0 documentation does not imply registry availability.

```bash
uv add ./artifacts/remote_skills-0.0.1-py3-none-any.whl
```

```python
from remote_skills import Origin, RemoteSkills

client = RemoteSkills(
    origins={
        "acme": Origin(
            url="https://skills.example.com",
            timeout=30.0,
            retries=2,
        )
    }
)

async with client.session("acme") as session:
    entries = await session.catalog()  # metadata only
    skill = await session.activate("code-review", "1.4.x")

    print(skill.version, skill.digest)
    print(skill.instructions)
    resources = await skill.list("references/")
    security = await skill.read("references/security.md")
    template = await skill.read_bytes("assets/template.bin")
```

The async context manager closes the session and releases cache leases. `read()` requires strict UTF-8; `read_bytes()` returns exact verified bytes. Resource reads come from the already downloaded complete artifact and do not issue another request.

## Aggregate and refresh

```python
aggregate = await client.catalog(strict=False)
for entry in aggregate.entries:
    print(entry.origin_alias, entry.name)
for failure in aggregate.failures:
    print(failure.origin_alias, failure.error.code)

await client.refresh("acme")  # future sessions only
```

The Python and TypeScript clients share stable snake-case error codes and the `cache-v1` disk contract. Syntax is idiomatic per language, but equivalent catalogs, scopes, versions, artifacts, requests, cache effects, and failures are intended to match.

For explicit offline creation, pass a bounded `StaleCatalog(max_age_seconds=...)` to `client.session`; see [cache and offline behavior](/docs/cache-and-offline).
