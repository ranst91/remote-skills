---
title: Integrations
description: Let your agent discover and load skills from a remote publisher.
---

Connect published skills to your agent's existing skill tools. The agent sees a catalog of names and descriptions, selects a skill that fits the request, and loads its instructions and supporting files when needed.

- [Vercel AI SDK](/docs/vercel-ai-sdk): give your AI SDK agent a skill loader and supporting-file reader.
- [Mastra](/docs/integrations/mastra): use Mastra's native Workspace tools to load, read, and search remote skills.

Each guide starts in your agent's application and walks through a working connection. If you are building your own skill integration, [Consume skills](/docs/consume) covers discovery, activation, and resource access through the SDK.
